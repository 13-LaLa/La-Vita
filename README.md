# La’Vita Health & Wellness Store

Premium responsive landing page for La’Vita Health & Wellness Store and La’Vita Fitness Club in Ekiti State, Nigeria.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production output is generated in `dist/`.

## Content architecture

Repeated services, pricing, fitness features, FAQs and partnership content live in `src/data/siteData.ts`. Page sections are assembled in `src/App.tsx`, while shared navigation, brand, reveal and FAQ components live in `src/components/`.

Official contact details and contextual WhatsApp messages are centralized in `src/data/siteData.ts`.
